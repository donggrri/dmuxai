# SPEC-spec-gate

Status: Implemented
Created: 2026-10-24

## 4. Requirements

| ID | Priority | Preconditions / trigger | Required observable result | Failure or boundary behavior | Evidence |
| --- | --- | --- | --- | --- | --- |
| FR-1800 | Must | `check-spec.py --all` is invoked from the crate root | Every `SPEC-*.md` in the specs dir is checked, allowlisted failures are tolerated, and exit code is 0 only when all non-allowlisted specs pass | Non-allowlisted failures, stale allowlist entries, or unknown entries make the gate exit 1 | TC-1800, TC-1801 |
| FR-1801 | Must | An allowlist entry names a spec that now passes, or a name with no matching file | The entry is reported as `STALE allowlist entry: remove SPEC-x.md` or as an unknown entry, and the run fails so the allowlist can only shrink | A correctly allowlisted failing spec keeps the run green | TC-1801 |
| FR-1802 | Must | `check-spec.py <file>` is invoked with a single spec path | The original single-file output and exit codes (0 pass, 1 fail, 2 usage) are preserved | Missing file or malformed spec exits 1; bad invocation exits 2 | TC-1802 |
| FR-1803 | Must | `check-tc-links.py` is invoked with test files and specs | Every defined TC is linked (strong `fn tc_<digits>_` or comment `TC-<digits>`) or allowlisted; tests referencing undefined TCs are rejected; exit 0 only when no orphans or undefined tests exist | Unlinked/unallowlisted TCs and tests referencing undefined TCs cause exit 1 | TC-1803, TC-1804 |
| FR-1804 | Must | Allowlist entries in `scripts/tc-link-allowlist.txt` | Each entry specifies `TC-<digits> <reason>` with a non-empty reason; linked entries are rejected as `STALE`; undefined TC entries or missing reasons cause exit 1 | Malformed, stale, or undefined allowlist entries fail the check so the list only shrinks | TC-1803, TC-1804 |
| FR-1805 | Must | `scripts/gate.sh` is invoked on Linux | Runs `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --all-features --no-fail-fast`, `python3 scripts/check-spec.py --all`, and `python3 scripts/check-tc-links.py` in that order; prints each step as `==> <step>` with timing; stops at the first failure and prints `GATE: FAIL at <step>` or `GATE: PASS` | `--quick` skips clippy and runs `cargo test --all-features --no-fail-fast --test spec_index`; `--keep-going` runs all steps and summarizes failures. The test step uses `--no-fail-fast` so cargo keeps running the remaining test targets after one target fails, and the step still fails when any target failed | TC-1805, TC-1807 |
| FR-2552 | Must | `check-tc-links.py` runs with the committed baseline `scripts/tc-link-baseline.json` (`{"comment_only": N, "allowlisted": M}`) | The run fails when the current comment-only count is above `comment_only` or the allowlisted count is above `allowlisted`, naming the count and the baseline; when a count is below its baseline the run passes and prints `lower the baseline: <key> <current>` | A missing or malformed baseline file fails the run (exit 1) | TC-2551 |
| FR-2553 | Must | `check-tc-links.py --base <git-ref>` | Allowlist entries that are not present in the base ref's `scripts/tc-link-allowlist.txt` fail as `NEW allowlist entry`; a baseline value above the base ref's baseline fails as `baseline raised` | When the ref cannot be resolved the run fails with a clear message; without `--base` these checks are skipped | TC-2552 |
| FR-2554 | Must | `check-tc-links.py --base <git-ref>` and a TC row added or changed in `docs/specs/SPEC-*.md` since the merge-base with that ref | Each such TC must have a strong link (`fn tc_<digits>_`); a comment-only or allowlisted link fails as `NEW TC needs a strong link: TC-x` | TC rows deleted in the diff are ignored | TC-2553 |
| FR-2555 | Must | `scripts/gate.sh` runs the TC-link step | It passes `--base origin/main` when that ref exists and otherwise runs without `--base`, printing which mode it used | — | TC-2554 |
| FR-1806 | Must | `--isolated` (default on) | Every step runs under `env` with all `DMUXAI_*` variables unset and `XDG_CONFIG_HOME` pointed at a fresh empty temp directory (removed on exit); HOME is left alone; the names of unset variables are printed (never their values), plus `isolated: XDG_CONFIG_HOME=<temp dir>` | `--no-isolated` leaves the environment untouched | TC-1806 |
| FR-1807 | Must | `--browser` is passed on Linux | After the normal steps, runs every `tests/web_*.rs` integration target in one cargo invocation (`cargo test --all-features --no-fail-fast --test <stem> ... -- --ignored`); documents that Chrome/chromium is required and skips with a clear message when none is found | Fails with a clear message when there are no `tests/web_*.rs` files or when the cargo output reports zero tests run | TC-1807 |
